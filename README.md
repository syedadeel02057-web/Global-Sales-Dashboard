# Sales Dashboard – Power BI

## Overview
This project presents an interactive **Sales Dashboard built using Microsoft Power BI**. The dashboard provides a visual analysis of sales performance across different categories, sub-categories, regions, states, segments, and time periods.

## Objectives
- Analyze overall sales and profit performance
- Compare sales across product categories and regions
- Identify the top 5 sub-categories by sales

## Dashboard Visuals
- **KPI Cards:** Total Sales, Total Profit, Profit Margin, Total Orders
- **Bar Chart:** Sales by Category
- **Bar Chart:** Sales by Region
- **Line Chart:** Sales by Week Number and Year
- **Donut Chart:** Sales by Segment
- **Top 5 Bar Chart:** Top 5 Sub-Categories by Sales

## Key Metrics
- Total Sales: **12.64M**
- Total Profit: **~1.47M**
- Profit Margin: **~12%**

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
